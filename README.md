# 🎮 IDEA App (Interactive Dynamic Entity Avatar)

**IDEA App** — это когда-то VTuber-студия для стримеров по Minecraft,
Изначальная версия была сделана два года назад при помощи нейросетей, а сейчас закрыт.

## 🚀 Что это такое?
Приложение позволяет управлять 3D-аватаром в стиле Minecraft с помощью веб-камеры и микрофона. Аватар реагирует на ваши движения, эмоции и события, происходящие в игре

## 🛠️ Технологии
- **Electron** — десктопная оболочка (сборка в `.exe`).
- **Three.js** — рендер 3D-графики и скинов.
- **MediaPipe** — трекинг лица и мимики через веб-камеру (FaceMesh).
- **WebSocket** — связь с модом Minecraft для приема игровых событий.
